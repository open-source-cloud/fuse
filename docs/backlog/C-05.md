## What the backlog says

> A gate is not a string. Define in Core the typed payload a gate carries — options (single/multi),
> confirm with summary, form with schema — and the correction semantics where rejecting one item of a
> multi-item confirmation re-opens **only that item** and preserves the rest without restarting the run.
>
> Core owns the schema and the state transitions; Enterprise owns rendering (D-02). This split is what
> lets a customer build their own frontend against the same contract.
>
> Depends on A-11 being resolved, since correction requires addressable per-turn state.

## Premise status

**net-new.** There is no typed gate payload to reproduce a defect in. Stage 1 has nothing to prove.

Four READ-confirmed facts about the primitives it lands on, all of which constrain the design:

- `system/wait` is a **placeholder body** intercepted by the handler; its declared inputs are
  `timeout`, `filter` and its outputs `data`, `timedOut` (`internal/packages/functions/system/wait.go`).
- The `Awakeable` row is `{ID, WorkflowID, ExecID, ThreadID, CreatedAt, Timeout, DeadlineAt, Status,
  Result}` (`internal/workflow/awakeable.go:24`) — no payload, no item structure.
- ⚠️ **The `timedOut` output is never true.** `AwakeableTimedOut` and `AwakeableCancelled` are declared
  and never assigned in production code; the only runtime value is the literal `false` at
  `workflow_handler.go:845`. A timed-out gate goes through `handleMsgTimeout` (`:551`) into a generic
  `FunctionError{"execution timeout exceeded"}` — indistinguishable from a crashed node — and the row
  stays `pending` forever.
- ⚠️ `DeadlineAt` is **always set** (`workflow_handler.go:775`, `now.Add(action.Timeout)`), so a
  no-timeout gate gets `DeadlineAt == CreatedAt`. Anything treating `deadline_at <= now()` as expired
  kills every untimed gate. That is **C-06**'s trap, and C-05's schema must not assume otherwise.

`POST /v1/awakeables/{awakeableID}/resolve` (`internal/handlers/resolve_awakeable.go:55`,
`mux_worker.go:270`) is the **only** awakeable route. It 404s on missing and 400s on non-pending —
the validation template this task's resolve path should follow.

## Route

**Deviation: no premise verification, and the decision record comes before any Go.**

1. `fuse-engine-researcher` — how a gate payload survives a restart today (it does not: `awakeable:created`
   is **never read** on replay, which is **A-02**'s clause), and what per-item correction needs from
   A-11's chosen option.
2. **Wait for A-11's ADR.** Correction semantics without addressable per-turn state cannot be
   specified honestly.
3. Decision record — **ADR** for the state transitions and correction semantics. A **SpecKit spec** is
   defensible instead/as well for the payload contract, because Enterprise (D-02) and third-party
   frontends build against it; the backlog mandates neither, so choose deliberately and say why.
4. `fuse-implementation-planner` → `fuse-go-implementer` → `fuse-code-reviewer`.

## Out of scope

- **A-11** owns per-execution addressing. **C-02** owns memory. **D-02** owns rendering — if a Core
  feature only makes sense with the console present, it belongs in the commercial layer.
- **C-06** owns durable timers, the expiry sweeper and the `DeadlineAt` trap. **C-07** owns exposing
  the awakeable id so a caller can reach the gate at all — C-05's payload is unusable without it, but
  that is a dependency to record, not work to absorb.
- **A-02** owns replaying `awakeable:created`. Do not fix the never-true `timedOut` here — record it
  and keep going; the backlog forbids drive-by fixes.
- Do not lift the agent tool denylist so an agent can open a gate (`agent_tools.go:18-24`) — that is
  an agent-execution-model change behind the HARD GATE.

## Decisions

**ADR required** for the correction semantics and state transitions; SpecKit optional for the payload
contract (see Route). Interacts with **ADR-0010 · Durable execution via an append-only journal**
(gate state is journal state), **ADR-0023 · Timeout enforcement via actor timers** (why a 72-hour gate
has no durable deadline today), **ADR-0032 · Sub-workflow composition** (a gate inside a child), and
**ADR-0013 · Workflow schema model and edge-based input mapping** (how a gate result re-enters the
graph). Next free ADR number is **0035** (coordinate with the other queued ADRs).

A new public HTTP contract that Enterprise and third-party frontends build against: the changelog rule
applies and **there is no CHANGELOG file in this repo** — raise it with the maintainer rather than
inventing a destination.
