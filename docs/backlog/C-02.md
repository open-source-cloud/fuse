## What the backlog says

> Working (run-scoped), episodic (past runs and conversations), semantic (durable facts).
> `ai/agent`'s `maxContextTokens`/`contextStrategy` trims inside one node execution and there is no
> graph-level equivalent, so conversation state grows unbounded in `aggregatedOutput` and in every
> journal payload.
>
> Semantic memory in markdown: human-readable, diffable, reviewable, auditable. An enterprise buyer
> can read what the system believes; a vector blob cannot be audited. Writes are proposals by default,
> resolved by policy or by a human gate.

## Premise status

**net-new.** There is no memory subsystem to reproduce a defect in. Two supporting facts are
READ-confirmed and should be carried into the design rather than re-derived:

- `internal/packages/functions/ai/context.go` trims **inside one node execution only**, and its
  budget is a heuristic — `estimateTokens` is `len(chars)/4` (`approxCharsPerToken = 4`, `:13`), not a
  tokenizer. Strategies are `drop-oldest` (default) and `summarize`.
- The transcript never leaves the goroutine: `messages`, `totalUsage` and `steps` are locals in
  `agentExecutor.run` (`agent.go:146-148`), so nothing about a turn is durable until the node
  finishes, and no run can be resumed mid-conversation.

Stage 1 (`fuse-premise-verifier`) has nothing to prove here and should be skipped; the pipeline's
verify-first rule protects against acting on a false premise, and there is no premise.

**Migration constraint.** Any new `JournalEntryType` needs an `ALTER TYPE journal_entry_type ADD
VALUE` migration — `migrations/000001_create_tables.up.sql:12` creates the enum with 13 values,
`000004` adds one more, and `internal/workflow/journal.go` already declares 18. A Go constant without
the migration is a runtime insert failure, not a compile error. Same trap that blocks C-08.

## Route

**Deviation: no premise verification, and one shared ADR with A-11.**

1. `fuse-engine-researcher` — what run-scoped state can reach an agent goroutine today (answer so far:
   nothing; `ExecutionInfo` carries only `WorkflowID`/`ExecID`/`Environment`/`Input`/`Finish`), and
   what the three memory kinds would each need to persist.
2. `write-adr` — **jointly with A-11**. The backlog says "overlaps A-11(a) — do them together", and
   A-11 option (a) *is* a turn-state store addressed by `(runID, agentNodeID, turn)`. One ADR should
   settle whether C-02's working memory and A-11's turn state are the same store. Next free number is
   **0035** (coordinate — A-03, A-04, A-05, A-09 and A-11 are all queued for numbers).
3. `fuse-implementation-planner` → `fuse-go-implementer` → `fuse-code-reviewer`.

"Do them together" is a design-coordination instruction, **not** permission to land A-11 and C-02 in
one PR. One task, one PR.

## Done when

Derived; the backlog gives no "Done when".

- [ ] An ADR (shared with A-11) records the three memory kinds, their storage, and their lifetimes,

- [ ] Working memory is addressable and durable across a restart, not a goroutine local.
- [ ] Conversation state no longer grows unbounded in `aggregatedOutput` and in every journal payload.
- [ ] Semantic memory is markdown, readable and diffable outside the engine.
- [ ] Semantic writes are proposals by default, with a resolution path (policy or human gate).
- [ ] Any new journal entry type ships with its enum migration; verified under `DB_DRIVER=postgres`.
