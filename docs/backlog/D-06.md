## What the backlog says

> Separate repo, separate release cadence, consumes Core's public API only. Starts once Tier A is green — building a console on an engine whose durability is unverified means debugging both at once.
>
> - **D-06 · Packaging.** Compose for pilot, Helm for production. Core's floor is already right — `CLUSTER_ENABLED=false`, `HA_ENABLED=false`, Postgres plus a writable path, embedded migrations, etcd and Redis optional. Do not regress it.

Governing rule: **"Core stays usable without Enterprise. If a Core feature only makes sense with the commercial layer, it belongs in the commercial layer."** Packaging is where that rule is easiest to break by accident — a chart that will not boot Core without the console has regressed it.

## Premise status

**net-new.** Nothing to reproduce in `core/`; stage 1 does not run. The floor is real and each half was verified in the tree this session:

- `CLUSTER_ENABLED` defaults `false` (`internal/app/config/config.go:97`); `HA_ENABLED` defaults `false` (`:145`); the writable path defaults to `OBJECT_STORE_FS_BASE_PATH=./data/fuse` (`:129`).
- Migrations are embedded — `//go:embed migrations/*.sql` at `internal/repositories/postgres/db.go:15`, so "run migrations" is not a packaging step.
- **Core already ships packaging**: `deploy/helm/fuse/{Chart.yaml,values.yaml,templates}` and one `docker-compose.yml` with `infra`/`ha`/`e2e` profiles. D-06 composes these; it does not fork or replace them.

One trap for any values file: `DB_DRIVER=postgres` with the default `OBJECT_STORE_DRIVER=memory` yields durable journal rows pointing into a store that dies with the process. **F-03** owns rejecting that pair in `Config.Validate`; until it lands, packaging must not ship it and cannot rely on the engine to refuse it.

Tier A is not green: F-01 completed 2026-08-11 with all three findings REPRODUCED against real Go 1.26.

## Out of scope

- **F-03** owns config validation of driver combinations — do not implement the guard in a chart. HA topology is Core's (**ADR-0018**), not a packaging decision.
- **D-01** owns the auth stack this deploys, **D-02** the console. Packaging them is D-06; building them is not.
- Do not make etcd or Redis mandatory, and do not flip either `*_ENABLED` default, to simplify an Enterprise topology — that is precisely the regression the backlog names.

## Decisions

**No Core ADR.** Consumes **ADR-0021 · Deployment and delivery architecture (CI/CD, Docker, Helm)** — read before writing any chart — plus **ADR-0018 · High availability: claims, clustering, schema replication**, **ADR-0003 · In-memory repositories by default, Postgres optional** (why the floor is what it is) and **ADR-0019 · Externalize large payloads to a pluggable object store** (why the writable path is not optional under Postgres).
