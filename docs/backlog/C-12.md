## What the backlog says

## Premise status

**UNVERIFIED, and doubly hedged.** Two narrowings, and both belong in the verifier's brief:

1. **The backlog's own hedge** — the entry is labelled "premise is inference" in its heading and says
   "No test covers it either way". This is the one Tier C task the backlog does not claim to know.
2. **The skill pack narrows it further, by reading `internal/workflow/workflow.go:226-257`:**
   `buildResumeAction` returns the first non-noop action **only on the zero-pending branch**
   (`:229-238`). With **one** pending thread it calls `replayPendingThread`; with **more than one** it
   builds a `RunParallelFunctionsAction` over all of them — **that branch fans out correctly**. So the
   reproducing scenario is specifically **a crash at a fan-out/join boundary with nothing still in
   flight**: several threads have recorded `thread:finished` and no `step:started` is uncompleted. Not
   "any multi-thread crash".

**A warning the test design must respect.** `Next()` mutates state and appends `step:started`, so the
actions discarded by that loop have *already* had side effects — the next restart picks them up as
pending. Expect the defect to look **intermittent across one restart and to self-heal across two**. Do
not encode that guess in the test; let the F-02 multi-thread scenario settle what actually happens.

If it does not reproduce, **the pipeline ends and the task closes with evidence.** That is a legitimate
and expected outcome here more than anywhere else in Tier C.

## Decisions

**Neither an ADR nor a SpecKit spec** if the fix is "fan out instead of returning the first action". It
tips to an **ADR** only if resume semantics change more broadly — in which case **ADR-0010 · Durable
execution via an append-only journal** needs an amendment or a superseding ADR rather than a silent code
change. Also interacts with **ADR-0011 · Thread model for fork/join and ForEach** (the fan-out/join
boundary this defect lives on) and **ADR-0012 · Configurable merge strategies at join nodes**. Next free
ADR number is **0035**.
