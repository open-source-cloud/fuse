## What the backlog says

> Provider-agnostic routing: OpenRouter as the default breadth play, Azure OpenAI / Bedrock / vLLM
> for self-hosted enterprise. Policy per node — `{primary, fallback[], maxCost, maxLatency}` — with
> budget enforcement and redaction at the boundary before anything reaches a telemetry sink.
>
> Self-hosted models are a launch requirement for the regulated customers in the pipeline, not a
> roadmap item.

## Premise status

**net-new.** No gateway, no routing policy, no budget enforcement and no redaction exist. Stage 1 has
nothing to reproduce and should be skipped.

What *does* exist, READ-confirmed, is the seam it would be built on — and it is thinner than the task
text implies:

- `pkg/llm/provider.go:82` is the whole provider contract: `Provider{Name(); Chat(ctx, ChatRequest)}`.
  **No capability metadata, no pricing.** `StreamingProvider` (`:101`) has **zero implementations**.
- Resolution is per-`(environment, name)` through `pkg/llm/registry.go`'s
  `ProviderFactory func(ctx, environment)`, so ADR-0031 secret refs already resolve per execution.
- Providers are named only at `internal/app/di/llm.go:19-23` — `openai`, `openrouter`, `ollama`,
  `gemini`, `anthropic` — and are **all disabled by default** (`config.go:66`, `envDefault:"false"`).
- `LLM_<PROVIDER>_TEMPERATURE` (`config.go:73`) is **dead config**, read nowhere. Only the per-node
  `temperature` input reaches a request (`chat.go:186` `optionalTemperature`).

## Route

**Deviation: no premise verification; an ADR precedes code.**

1. `fuse-engine-researcher` — where the gateway sits relative to `pkg/llm.Provider`: a decorating
   provider, a registry-level router, or a new layer above both. Include: what a fallback does to the
   async `Finish` contract, and where redaction can run before a telemetry sink sees a payload.
2. `write-adr` — routing policy shape, budget enforcement point, redaction boundary, and the
   self-hosted requirement. Next free number is **0035** (coordinate with the other queued ADRs).
3. `fuse-implementation-planner` → `fuse-go-implementer` → `fuse-code-reviewer`.

`fuse-protocol-spec-author` is **not** involved — this is not the remote-node wire surface.

## Done when

Derived; the backlog gives no "Done when".

- [ ] A per-node policy `{primary, fallback[], maxCost, maxLatency}` is declarable and enforced.
- [ ] A self-hosted provider (vLLM or equivalent) works through the same path as a hosted one, with no
      special-casing at the call site.
- [ ] Budgets are enforced at the gateway, not in each `ai/*` function.
- [ ] Redaction runs at the boundary **before** anything reaches a telemetry sink — asserted by a test
      that inspects what the sink received.
- [ ] `maxCost` has a stated data source, or the ADR records that cost cannot be computed in Core
      today and says what C-04 must supply.
- [ ] `make lint && make build && make test` green.

## Out of scope

- **C-04** owns GenAI telemetry and cost attribution on the trace, and *depends on this task*. Meter

- **C-02** owns memory; summarisation is an `ai/context.go` concern, not a routing concern.
- Do not fix the dead `LLM_<PROVIDER>_TEMPERATURE` config as a drive-by — record it and keep going.
- Do not implement `StreamingProvider` opportunistically; nothing in the backlog asks for streaming.

## Decisions

**ADR required** — provider routing and budget enforcement are costly to reverse and touch a public
package. Interacts with **ADR-0006 · LLM provider abstraction & multi-provider strategy** (the decision
this extends; it will need an amendment or a superseding ADR), **ADR-0029 · LLM cost & token-usage
tracking and budgets** (which defers the pricing table — the gap `maxCost` runs into), **ADR-0031 ·
Settings, secrets & environments** (per-environment provider credentials), and **ADR-0016 ·
Multi-scope concurrency control and rate limiting** (the existing throttling concepts a gateway must
not duplicate).

`pkg/llm` is a **public package**: the changelog rule applies, and **there is no CHANGELOG file in this
repo** — raise it with the maintainer rather than inventing a destination.
